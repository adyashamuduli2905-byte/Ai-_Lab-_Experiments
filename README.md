# AI Lab Experiments

This repository contains practical Artificial Intelligence (AI) lab experiments implemented using Python and Google Colab as part of my B.Tech CSE (AI & ML) coursework.

## Experiments Performed

The repository includes implementations of the following AI algorithms and problems:

1. Hill Climbing Algorithm
2. Water Jug Problem
3. Breadth-First Search (BFS)
4. Depth-First Search (DFS)
5. Travelling Salesman Problem (TSP)
6. Minimax Algorithm
7. 8 Queens Problem
8. A\* Search Algorithm
9. Alpha-Beta Pruning
10. Tic-Tac-Toe using AI



## Technologies Used

- Python
- Google Colab
- GitHub

## Learning Objectives

- Understand fundamental Artificial Intelligence algorithms.
- Implement search and optimization techniques.
- Explore adversarial search and game-playing algorithms.
- Develop problem-solving skills through practical implementation.
